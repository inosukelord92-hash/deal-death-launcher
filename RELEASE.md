# DEAL DEATH v1.3.0

Minecraft: Java Edition launcher for Windows.

## What's new

- **Minecraft now actually launches** — Play downloads the game, installs the selected mod loader and starts it.
- **Official Microsoft sign-in** with Minecraft ownership verification.
- Fabric, Forge, NeoForge and Quilt support.
- Automatic Java runtime download (Temurin 8 / 17 / 21 / 25).
- Live download progress on the Play button and per-instance launch logs.
- Clear error messages for sign-in, ownership, Java and download problems.
- Grass block icon on every version and instance card.
- Modrinth modpack installs now say "Press Play" to finish setup.

## Requirements

- Windows 10/11 (64-bit)
- A Microsoft account that owns Minecraft: Java Edition
- Internet connection for the first launch

## Install

Download `DEAL DEATH Setup 1.3.0.exe` below and run it. The installer is not
code-signed, so Windows SmartScreen may show a warning — choose **More info →
Run anyway**.

## Notes

Offline / cracked accounts are not supported. DEAL DEATH signs in through
Microsoft's official login page and checks game ownership with the Xbox and
Minecraft services.
