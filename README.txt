DEAL DEATH Launcher
1. Install Node.js 18+.
2. In this folder run:  npm install
3. Then run:            npm start
4. Build the Windows installer with:  npm run build

Minecraft: Java Edition is required. Sign in with the Microsoft account that
owns the game (avatar in the sidebar). Offline/cracked accounts are not supported.

Instances are stored in the app's user-data folder: <userData>/instances/<instance id>/
(use Files > Open folder inside an instance).
CurseForge needs a free API key from console.curseforge.com (paste it in the Content Hub filters panel).
